# Tortoise Grand Prix

A tortoise F1 grand prix. The hero tortoise #44 charges down the track with a
rear spoiler, twin jet engines and racing glasses, its carapace covered in
sponsor stickers. Rival #7 runs alongside, and a fourth tortoise is spinning
out behind them in a cloud of dust and flying stickers.

`main.py` ships the artwork: it copies `entry.jpg` byte-for-byte to
`entry.png` in the output directory ($MAKEFUN_OUTPUT_DIR, or /output).
